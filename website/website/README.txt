SPAIN TRAVEL DIARY

This is a simple student-level website made using HTML and inline CSS.
All styling is written inside the style attributes in index.html.
No separate CSS file is required.

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the SpainTravelDiaryBalanced folder.
3. Double-click index.html to view the website in a browser.
4. To edit it, open index.html in Notepad or VS Code.

The photos are loaded from Unsplash, so an internet connection is needed to display them.
